> software for general contractors, general planners, project developers and
> architects. The platform covers lean-construction scheduling, day-to-day project

## API access

koppla has a real API but it is **not a public developer offering**. An "Offene
Schnittstelle / API" is listed as an included capability of the Enterprise plan
only. There is no developer portal, no API reference, no SDK, no sandbox and no
self-service signup. Access is provisioned per contract.

- Primary API: GraphQL at https://api.koppla.de/api/graphql/v1
- A REST API is in progress (deprecation notes in the GraphQL schema point at it;
  the web client references https://api-v2.koppla.de). It is undocumented publicly.
- Auth: bearer token, WorkOS-backed SSO. Unauthenticated data requests return
  `extensions.code = UNAUTHENTICATED`.
- Schema introspection is answered without credentials, which is how the schema in
  this repo was captured. Data access itself is correctly gated.

## Agent notes

- Every list is a Relay cursor connection: `first` + `after`, loop while
  `pageInfo.hasNextPage`.
- **There is no idempotency mechanism.** Retried mutations duplicate data.
  Verify with a read before retrying any write. `clientMutationId` is correlation
  only, not deduplication.
- Errors come back as HTTP 200 with an `errors[]` array; gateway rejections come
  back as HTTP 403 plain JSON. Handle both.
- 45 schema fields are deprecated with stated replacements — consult the SDL
  before selecting fields. Prefer `ticketsV2`, `createOrderStatusReports`,
  `createOrderPhotoV2`, and the `*V2` siblings generally.
- koppla is multi-tenant; several root queries require a `tenant` ID.
  `userProjects` scopes to your own memberships and needs none.
